Manual Paso a Paso: Blog Interactivo

Unidad Didáctica: Programación Multimedia Básica | Caso práctico: Feria "El Baratillo"

1. Introducción y Arquitectura del Proyecto

Este manual guiará al estudiante en la construcción de un blog web multimedia de nivel básico. El objetivo es aprender la integración real de las tres tecnologías pilares de la web junto con el elemento de renderizado gráfico <canvas>.

Estructura de Archivos

El alumno debe crear una carpeta raíz llamada feria-baratillo y dentro de ella depositar los siguientes tres archivos indispensables:

Archivo Tecnología Función en el Proyecto
index.html HTML5 Estructura semántica del blog y declaración de zonas de contenido.
estilos.css CSS3 Presentación visual, maquetación adaptativa y transiciones dinámicas.
script.js JavaScript Control de la interactividad del usuario y renderizado de gráficos en el Canvas.

4. Lógica e Interacción con Canvas script.js

JavaScript maneja dos tareas cruciales: el dibujo del banner/logo en tiempo de ejecución (Canvas API) y la actualización asíncrona del panel de información (DOM).

// --- 1. DIBUJO PROGRAMÁTICO DEL LOGO (CANVAS) ---
function crearLogo() {
    const canvas = document.getElementById('logoCanvas');
    const ctx = canvas.getContext('2d');

    // Fondo del Logotipo
    ctx.fillStyle = '#ef4444'; // Color rojo vivo
    ctx.fillRect(10, 10, 380, 60);

    // Borde Decorativo de Feria
    ctx.strokeStyle = '#f59e0b'; // Amarillo/Ámbar
    ctx.lineWidth = 4;
    ctx.strokeRect(15, 15, 370, 40);

    // Tipografía y Efecto de Sombra del Texto
    ctx.fillStyle = '#ffffff';
    ctx.font = 'bold 24px Arial';
    ctx.textAlign = 'center';
    ctx.shadowColor = 'rgba(0, 0, 0, 0.5)';
    ctx.shadowOffsetX = 3;
    ctx.shadowOffsetY = 3;
    
    // Inyección del texto en coordenadas X=200, Y=43
    ctx.fillText('FERIA "EL BARATILLO"', 200, 43);
}

// Iniciar dibujo automáticamente al cargar el documento
window.onload = crearLogo;


// --- 2. GESTIÓN DE INTERACTIVIDAD DEL BLOG ---
function mostrarDetalle(nombre, precio, descripcion) {
    const contenedorInfo = document.getElementById('vista-previa');
    
    // Modificación dinámica del DOM mediante plantillas literales
    contenedorInfo.innerHTML = `
        
${nombre}

        
Precio de Feria: ${precio}

        
${descripcion}

        
    `;
}
💡 Nota Pedagógica para el Docente: El uso del objeto ctx (Contexto de Renderizado 2D) permite explicar de forma práctica el plano cartesiano informático, donde las coordenadas (0,0) inician en la esquina superior izquierda del Canvas.

5. Evaluación de Resultados

Al ejecutar el proyecto de forma correcta, el alumno habrá aprendido a:

  • Vincular e interactuar entre archivos de diferente naturaleza tecnológica.
  • Comprender cómo se manipulan pixeles y geometrías bidimensionales básicas mediante código estructurado.
  • Modificar de forma dinámica elementos en pantalla basándose en las acciones explícitas del usuario.
